## Run

```powershell
npm install
npm start
```

Open `http://localhost:3000`.

## Local AI

Ollama is supported with no API key. Default model: `llama3.2:3b`.

Optional `.env`:

```env
OLLAMA_URL=http://127.0.0.1:11434
OLLAMA_MODEL=llama3.2:3b
```
