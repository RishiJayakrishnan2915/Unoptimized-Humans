- Member 2: Dan Sunil - Providence College Of Engineering, Chengannur

## Project Description

WEB-O-TRON 2000™ is a deliberately useless retro Internet portal that confidently misunderstands everything you search for.

Instead of giving you what you asked for, it sends you into a completely unrelated corner of the Internet, surrounded by fake utilities, games, AI, radio, videos, certificates, system errors, and other completely unnecessary features.

## The Problem (that doesn't exist)

The Internet has become far too useful.

You search for something and actually find it. You click something and it actually works. You ask a question and receive a relevant answer.

WEB-O-TRON 2000™ solves the completely nonexistent problem of the Internet being helpful.

## The Solution (that nobody asked for)

WEB-O-TRON 2000™ deliberately misunderstands the user.

Search for `cats` and you might get taxes.

Search for `football` and you might get gardening.

Search for `Python` and you might get sandwiches.

The system randomly selects an unrelated category, retrieves real Internet content, and presents it through an intentionally broken early-2000s Internet interface.

It is not broken.

It is working exactly as designed.

### Implementation

WEB-O-TRON 2000™ consists of a browser-based frontend and a Node.js backend.

The frontend contains the retro Internet interface, Wrongness Engine, games, radio, video portal, fake utilities, AI assistant, certificates, system errors, and other interactive features.

The backend provides an AI gateway that connects the browser to a locally running Ollama model.

The Wrongness Engine intentionally maps user searches to unrelated categories before retrieving Internet content.

The result is a fully functional system whose primary purpose is to be completely useless.

# Installation

Clone the repository:

```bash
git clone https://github.com/RishiJayakrishnan2915/useless_project_temp.git
cd useless_project_temp
```

Install the required dependencies:

```bash
npm install
```

Make sure Ollama is installed and running locally with the `llama3.2:3b` model.

Create a `.env` file in the project root:

```env
OLLAMA_URL=http://127.0.0.1:11434
OLLAMA_MODEL=llama3.2:3b
```

No external API key is required for the local AI gateway.

# Run

Start the WEB-O-TRON 2000™ server:

```bash
node server.js
```

Then open:

```text
http://localhost:3000
```

The browser interface communicates with the Node.js backend, which connects to the locally running Ollama model for the AI features.

# How It Works

```text
                    USER
                      │
                      ▼
               SEARCH QUERY
                      │
                      ▼
              WRONGNESS ENGINE
                      │
                      ▼
            UNRELATED CATEGORY
                      │
                      ▼
          INTERNET / API RETRIEVAL
                      │
                      ▼
          RETRO WEB-O-TRON UI
                      │
                      ▼
                 CONFUSION
```

The Wrongness Engine is the core concept behind the project.

Instead of attempting to understand a search correctly, the system intentionally redirects it toward an unrelated subject.

Example:

```text
cats       → taxes
football   → gardening
Python     → sandwiches
cars       → cooking
music      → plumbing
weather    → dinosaurs
```

The system then retrieves content related to the deliberately incorrect category and displays it through the WEB-O-TRON 2000™ interface.

# AI System

WEB-O-TRON 2000™ includes a locally hosted AI assistant.

The browser communicates with the Node.js backend through an API gateway:

```text
WEB-O-TRON
     │
     ▼
Node.js / Express
     │
     ▼
Local Ollama API
     │
     ▼
llama3.2:3b
```

The AI system does not require an external API key.

# What Makes It Useless?

Most software is designed to make something easier, faster, or more useful.

WEB-O-TRON 2000™ does the opposite.

It takes a perfectly reasonable search query and intentionally makes the result less useful.

It adds unnecessary buttons.

It creates fake errors.

It generates pointless statistics.

It gives certificates for doing nothing.

It has an arcade nobody asked for.

It has an AI assistant that exists inside a fake Internet from 2003.

It is an over-engineered solution to a problem that never existed.

# Conclusion

WEB-O-TRON 2000™ is a fully functional implementation of a completely unnecessary idea.

The project combines modern web technologies, local AI, APIs, procedural systems, games, audio, video, and retro interface design to recreate an intentionally useless early-2000s Internet experience.

It works.

It is useless.

That is the point.
